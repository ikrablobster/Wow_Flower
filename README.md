# Wow Flower

Адаптивний лендинг квіткової крамниці: популярні букети, каталог, акції, блок «Не знайшли букет?», про нас та відгуки.

Демо: https://ikrablobster.github.io/Wow_Flower/

## Стек

HTML, CSS (БЕМ), JavaScript, Swiper (слайдери), WebP/AVIF через `<picture>`.

## Що зроблено

- Адаптивна верстка (десктоп, планшет, мобільний) з мобільним меню-бургером.
- Слайдери «Популярне», «Каталог» (сітка в 2 ряди) та «Відгуки».
- Підписка зі знижкою та форма зворотного дзвінка.
- Доступність: один `h1`, якорі секцій, підписи до форм і кнопок, контраст не нижче 4.5:1, `:focus-visible`, `prefers-reduced-motion`.

## Примітки

Форми поки що не відправляють дані: для цього потрібен endpoint (наприклад, Formspree або Telegram-бот).
